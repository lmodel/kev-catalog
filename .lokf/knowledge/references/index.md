# References

* [CISA's KEV JSON schema](cisa-kev-json-schema.md) - CISA's JSON schema for the KEV catalog, draft-07, the file this project renders, at the edition of 2026-09-17. It states no version of its own. CISA serves it from `www.cisa.gov`, and `cisagov/kev-data` holds the same bytes.
* [cisagov/kev-data](cisagov-kev-data.md) - The official GitHub mirror of CISA's KEV data files, at `https://github.com/cisagov/kev-data`, default branch `develop`: the JSON and CSV catalogue, the JSON schema, and a CC0 licence. This project pins the schema and one dated catalogue from it.
* [Binding Operational Directive 26-04](bod-26-04.md) - Binding Operational Directive (BOD) 26-04, *Prioritizing Security Updates Based on Risk*, which kev-data's README and CISA's JSON schema now cite for the catalog. CISA's page answered a plain client with 403 on 2026-11-03, so this project cites it by address and restates none of its terms.
